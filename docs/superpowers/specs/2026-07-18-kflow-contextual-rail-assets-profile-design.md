# KFlow 场景化右栏、智能资产与个人页设计

日期：2026-07-18

## 目标

让 KFlow 的辅助能力随当前模式、任务和 Agent 变化，消除无关的代码、测试入口；补齐 Skill、插件与 Codex 风格个人页，同时保持 Agent 提效工具的产品定位。

## 一、场景化右栏

右栏不再使用全局固定工具集合。页面根据 `mode + view + agent + requirement/task evidence` 计算可见工具，默认收起，最多显示 4 个高相关入口；执行日志只在任务执行中或已有执行记录时出现。

| 场景 | 右栏入口 |
| --- | --- |
| 日常办公首页 | 最近文件、常用 Agent、连接来源 |
| 会议纪要 | 原始材料、纪要预览、待办事项、引用来源 |
| 数据分析 | 数据表、图表预览、分析依据、导出结果 |
| PPT | 大纲、页面预览、素材引用、导出结果 |
| 需求分析 | 需求上下文、分析结论、待确认问题、执行记录 |
| 原型设计 | 页面预览、组件结构、交互说明、引用上下文 |
| PRD 撰写 | 文档预览、PDF、版本修改、引用上下文 |
| 前后端开发 | 文件变更、代码 Diff、运行日志、引用代码 |
| 代码审查 | 代码 Diff、问题清单、审查结论、引用规范 |
| 测试 | 测试用例、执行报告、失败详情、运行日志 |

约束：

- 日常办公不显示代码 Diff、代码库或测试报告。
- 产品设计阶段不显示测试入口；仅当切换到测试 Agent 或当前任务已有测试证据时出现。
- 不可用能力不占位，不用禁用图标制造噪声。
- 切换任务或 Agent 后，若当前打开的抽屉不再适用，自动关闭。

实现上新增一个纯函数式工具解析器，输入当前模式、视图、Agent 和证据，输出右栏工具定义；右栏只负责渲染和选择。

## 二、智能资产

智能资产分类调整为：Agent、Skill、插件、知识库、记忆库、代码库、工具连接。

### Skill

- 区分个人、团队、系统来源。
- 卡片展示名称、用途、适用场景、触发方式、启用状态与维护者。
- 支持搜索、启用/停用和查看详情；Demo 使用本地确定性状态。

### 插件

- 展示插件名称、提供的能力、连接状态、授权范围和包含的工具数量。
- 支持查看详情、连接/断开和权限概览；不实现真实 OAuth。
- “工具连接”保留企业需求、测试等单一连接；“插件”表示可安装的复合能力包，两者不混用。

## 三、Codex 风格个人页

点击侧栏底部个人信息进入个人页；齿轮作为同一页面的快捷入口。

页面采用轻量设置结构：

1. 账号与企业工作区：头像、姓名、邮箱、组织、当前工作区和项目角色概览。
2. Agent 偏好：默认模型、推理强度、沟通风格、默认权限模式、常用 Agent。
3. Skill 与插件：已启用的个人 Skill、常用插件和进入智能资产的快捷入口。
4. 连接与权限：已连接企业系统、数据访问范围和权限说明。
5. 通知：任务完成、需要确认、测试失败等通知偏好。

不包含计费、复杂安全策略、组织审计或后台管理员功能。

## 四、交互与状态

- 新增 `profile` 视图和智能资产 `skill`、`plugin` 类型。
- 个人偏好、Skill/插件开关使用页面内本地状态，刷新后重置，符合 Demo 定位。
- 右栏工具选择继续复用现有抽屉与 `PreviewKind`；新增办公/产品所需的轻量预览类型与空状态。
- 所有新入口提供唯一可访问名称；个人页和资产标签支持键盘操作。

## 五、验证

- 单元测试覆盖工具解析器的办公、产品、开发、审查、测试五类映射。
- 集成测试覆盖：智能资产包含 Skill/插件；个人页可进入；办公任务无代码/测试入口；原型/PRD 无测试入口；开发与测试任务各自显示正确工具；切换 Agent 后不适用抽屉关闭。
- 最终运行测试、Lint、生产构建与全分支空白检查。

## 非目标

- 真实插件安装、OAuth、账号安全或计费。
- 自定义右栏编排器。
- Agent 协作编排或新的项目管理流程。
